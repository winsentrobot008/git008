RoastBro Shortcuts
===================
Location: C:\Users\aoogoost\Desktop\Projekt\git008\RoastBro

To create a desktop shortcut:
1. Right-click run_dashboard.bat
2. Select "Create shortcut"
3. Move shortcut to Desktop
4. Right-click shortcut → Properties
5. Click "Change Icon" → Browse to assets/icons/roastbro.ico

Quick Start:
  Double-click "RoastBro Control Panel.lnk" on Desktop
  OR
  Run: RoastBro/run_dashboard.bat

The dashboard opens at: http://localhost:8501
