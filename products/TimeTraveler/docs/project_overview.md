# TimeTraveler — AI 私密 4D 情绪空间系统

> Local Privacy + Cloud Compute

## 项目简介

TimeTraveler 是一个 AI 驱动的私密 4D 情绪空间系统。用户可以将自己的视频转换成可进入的 4D 世界，并在私密房间中与 AI 角色进行情绪、关系、心理层面的深度互动体验。

## 产品愿景

让每个人都能将自己的记忆与情感转化为可进入、可交互、可成长的 4D 情绪空间，在绝对隐私的环境中与 AI 进行有意义的心理与情感对话。

## 核心价值

| 价值 | 说明 |
|------|------|
| **绝对隐私** | 用户视频数据在本地预处理，云端仅接收匿名化特征包 |
| **4D 空间化** | 将 2D 视频转换为可漫游、可交互的 4D 情绪场景 |
| **AI 情感陪伴** | 基于用户情绪状态动态调整的 AI 角色互动系统 |
| **私密房间制度** | 每个用户拥有独立加密房间，数据完全隔离 |
| **渐进式算力** | 本地轻量处理 + 云端加速渲染，按需付费 |

## 三层算力架构

```
┌─────────────────────────────────────────────────────────────┐
│                     Layer 1: 本地预处理                       │
│  (Local Privacy First)                                       │
│  ├─ 视频降采样 / 关键帧提取                                  │
│  ├─ 人脸模糊 / 敏感信息脱敏                                  │
│  ├─ 情绪特征提取 (轻量模型)                                  │
│  └─ 打包为匿名化特征包 (.afp) → 上传云端                    │
├─────────────────────────────────────────────────────────────┤
│                     Layer 2: 云端加速                         │
│  (Cloud Compute Boost)                                       │
│  ├─ 4D 场景重建 (Gaussian Splatting)                         │
│  ├─ AI 角色生成与情绪注入                                    │
│  ├─ 高精度渲染 (可选的 RTX 加速)                             │
│  └─ 返回加密场景包 → 本地解密渲染                            │
├─────────────────────────────────────────────────────────────┤
│                     Layer 3: 本地渲染                         │
│  (Local Rendering & Interaction)                             │
│  ├─ 本地 GPU 加速渲染 4D 场景                                │
│  ├─ AI 角色实时对话与情绪反馈                                │
│  ├─ 用户交互 (漫游/选择/对话)                                │
│  └─ 数据不出房间 (端到端加密)                                │
└─────────────────────────────────────────────────────────────┘
```

## 私密房间制度

每个 TimeTraveler 用户拥有一个独立的加密房间：

- **房间 ID**: 由用户主密钥派生，全球唯一
- **数据存储**: 本地 SQLCipher + 云端加密备份
- **访问控制**: 只有持有主密钥的用户可进入
- **会话隔离**: 每次对话生成独立会话密钥
- **彻底删除**: 用户可一键销毁房间所有数据
