# TimeTraveler — 私密房间系统

## 房间生命周期

```
创建房间
  ↓
┌─────────────────────────────────────┐
│        房间初始化                     │
│  ├─ 生成房间 ID (UUID v4)           │
│  ├─ 派生房间加密密钥                 │
│  ├─ 初始化本地 SQLCipher 数据库      │
│  └─ 创建房间配置 (theme/avatar/...) │
└─────────────────────────────────────┘
  ↓
┌─────────────────────────────────────┐
│        导入视频 → 创建 4D 场景       │
│  ├─ 视频预处理 → 匿名化特征包        │
│  ├─ 云端 4D 重建                    │
│  ├─ 场景加密存储                    │
│  └─ 关联到房间                      │
└─────────────────────────────────────┘
  ↓
┌─────────────────────────────────────┐
│        AI 角色互动                   │
│  ├─ 进入房间 → 加载场景 + 角色       │
│  ├─ 实时对话 + 情绪反馈              │
│  ├─ 场景动态调整 (光照/氛围)         │
│  └─ 会话记录 → 长期记忆             │
└─────────────────────────────────────┘
  ↓
┌─────────────────────────────────────┐
│        销毁房间                      │
│  ├─ 删除本地数据库                   │
│  ├─ 请求云端删除备份                 │
│  ├─ 销毁加密密钥                     │
│  └─ 房间 ID 标记为已销毁             │
└─────────────────────────────────────┘
```

## 加密架构

```
用户主密钥 (User Master Key)
  ├─ 从用户密码 + 硬件 ID 派生 (Argon2id)
  ├─ 长度: 256 位
  └─ 从不离开本地

房间密钥 (Room Key)
  ├─ 从主密钥 + 房间 ID 派生 (HKDF-SHA256)
  ├─ 每房间独立
  └─ 用于 AES-256-GCM 加密所有房间数据

会话密钥 (Session Key)
  ├─ 每次对话随机生成
  ├─ 使用房间密钥加密传输
  └─ 对话结束后销毁
```

## 本地存储结构

```
room_system/
├── storage_local/
│   ├── rooms/                    # 房间数据库
│   │   └── {room_id}/
│   │       ├── config.json       # 房间配置 (加密)
│   │       ├── scenes/           # 4D 场景数据 (加密)
│   │       ├── memories/         # AI 记忆 (加密)
│   │       └── media/            # 用户媒体 (加密)
│   └── keys.db                   # 密钥存储 (硬件加密)
└── encryption/
    ├── key_derivation.py         # 密钥派生
    ├── cipher.py                 # 加解密
    └── signature.py              # 签名验证
```
