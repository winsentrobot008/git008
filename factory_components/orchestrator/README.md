# 白龙马（Local AGI Orchestrator）

白龙马是一个本地自动化调度系统，用于连接 AGI、ZOO（任务拆解与代码生成）、TRAE（本地执行环境）、以及本地 PC 的操作能力。

它的目标是成为一个"本地传令兵 + 执行官"，自动完成任务、收集反馈、汇报结果，并形成闭环工作流。

## 📌 项目愿景

构建一个能够：

- 自动理解 AGI 的任务
- 自动操作你的本地电脑
- 自动调度 ZOO 生成代码与任务
- 自动在 TRAE 中执行脚本、构建、测试
- 自动监控文件、网页、仓库、日志
- 自动汇报结果给 AGI
- 自动继续下一步任务

的 **本地 AGI 工作总管（白龙马）** 。

## 🚀 核心功能说明

### 1. 任务接收（AGI → 白龙马）

- 接收来自 AGI 的结构化任务
- 支持自动模式与人工确认模式
- 支持从对话内容中提取任务目标

### 2. 本地 PC 操作

- 打开浏览器、窗口、应用
- 控制鼠标、键盘、快捷键
- 自动化操作 ZOO、TRAE、文件管理器
- 截屏 + OCR + 简单视觉识别

### 3. ZOO 调度

- 自动创建项目
- 自动调用工具
- 自动生成代码、脚本、配置
- 自动导出结果并保存到本地

### 4. TRAE 执行

- 运行脚本
- 构建项目
- 执行测试
- 生成产物（APP、网页、视频等）

### 5. 本地环境监控

- 文件夹变化
- 日志文件
- 构建产物
- 配置文件
- 版本号与依赖情况

### 6. 网络与仓库监控

- 访问网页并检查状态
- 检查仓库分支、提交、CI 状态
- 收集接口返回与错误信息

### 7. 结果汇报（白龙马 → AGI）

- 整理所有执行结果
- 生成结构化报告
- 发送给 AGI
- AGI 分析后生成下一步任务
- 白龙马继续执行，形成闭环

🧩 模块蓝图（详细说明）
白龙马由六大核心模块组成，每个模块对应一个开源组件或本地系统。

1. 感知层（Perception Layer）
负责"看见"你的电脑和环境。

功能
截屏

OCR 识别

图像定位按钮

网页状态检查

文件夹变化监控

仓库状态监控

技术组件
TagUI + SikuliX（视觉识别 + OCR）

Huginn Agents（网页监控、文件监控）

2. 行动层（Action Layer）
负责"动手"执行操作。

功能
鼠标点击

键盘输入

打开浏览器

操作 ZOO 页面

操作 TRAE IDE

执行本地脚本

控制窗口

技术组件
TagUI（桌面自动化 + 浏览器自动化）

Playwright（可选）（更强的浏览器控制）

3. 调度层（Orchestration Layer）
负责"安排任务顺序、触发执行、管理工作流"。

功能
工作流编排

任务拆解

工具调用

条件判断

自动触发下一步

技术组件
n8n（工作流引擎）

Huginn（事件驱动 Agent）

4. 执行层（Execution Layer）
负责"真正干活"。

功能
运行 ZOO 生成的代码

构建项目

执行测试

生成 APP / 网页 / 视频

运行自动化脚本

技术组件
TRAE（你的本地 IDE + 执行环境）

OpenInterpreter（可选）（本地代码执行）

5. 工具层（Tool Layer）
负责"生成代码、脚本、配置、任务"。

功能
代码生成

脚本生成

配置生成

项目初始化

自动化任务生成

技术组件
ZOO（你的代码生成与任务拆解系统）

6. 汇报层（Report Layer）
负责"把所有结果汇总给 AGI，让 AGI继续规划下一步"。

功能
汇总执行结果

汇总日志

汇总文件变化

汇总网页状态

汇总仓库状态

生成结构化报告

发送给 AGI

技术组件
Huginn Agents（数据收集）

n8n（报告生成工作流）

AGI Bridge（与 AGI通信）

🔄 白龙马闭环工作流（核心逻辑）
代码
你 → AGI → 白龙马 → ZOO → TRAE → 本地环境 → 白龙马 → AGI → 下一步
1. 你给目标
例如：
"生成一个 APP 并测试所有功能。"

2. AGI 拆任务
生成结构化任务 → 发给白龙马

3. 白龙马执行
TagUI 操作 PC → ZOO 生成代码 → TRAE 执行 → Huginn 监控

4. 白龙马汇报
收集所有结果 → 发送给 AGI

5. AGI 分析
生成下一步任务

6. 白龙马继续执行
形成自动化闭环
